## 17:32 — CentOS Stream 10 enablement: CRB repo, pcre-devel drop, brew-rsync lesson

**Context:** First `centos10-x86-64` runtime build attempt (3.13.18) on a CS10
EC2 host failed in `build_linux_base_dependencies`. centos10 is wired into
version blocks 3.10–3.15 only (user unwired 3.7–3.9 after initially adding
all nine).

**Decisions / events:**
- dnf `--installroot` failed: `gdbm-devel`, `libtirpc-devel`,
  `gobject-introspection-devel`, `libXdmcp-devel` are not in CS10
  BaseOS/AppStream/Extras — they moved to **CRB** on RHEL/CS10. Host-side fix
  (done): `sudo dnf config-manager --set-enabled crb`. Works because the
  installroot yum reads the *host's* repo config. The centos9 build host
  almost certainly has CRB enabled already (`gobject-introspection-devel` is
  CRB-only there too).
- `pcre-devel` (PCRE1) was **removed entirely from RHEL/CS10** — CRB won't
  help. Fixed in `build_runtime.sh` (applied, uncommitted): platform-gated
  `local -a pcre1_devel=("pcre-devel")`, emptied for `*'centos10-'*`, expanded
  as `"${pcre1_devel[@]}"` in the yum list (follows the `amzn2-` per-platform
  precedent inside the same function). Safe because CS10's glib2 (2.80+) links
  libpcre2 (pulled via pcre2-devel) and the `"libpcre"` prefix in the libs
  allowlist still matches `libpcre2*` files.
- rsync failed every copy with "ACLs are not supported on this client":
  the host had Homebrew rsync 3.5.2 (built **without** libacl — its
  `--version` capabilities literally say "no ACLs") shadowing the distro
  `rsync-3.5.0-1.el10`, and the script's `rsync -aHAXE` passes `-A`.
  Host-side fix (done): `brew uninstall rsync`; `/bin/rsync` (ACL-capable)
  now resolves.

**Lessons:**
- Homebrew-on-Linux rsync is compiled without ACL support; any `-A` rsync in
  these scripts hard-fails if linuxbrew shadows the distro binary on a build
  host. Prefer distro rsync on build hosts.
- dnf transactions are all-or-nothing: one unresolvable package aborts the
  whole install, so a single missing `-devel` kills the entire deps stage.

      (dnf installroot clean, distro rsync in use). Full build still running.
